## Selected projects

### [Flame in Freefall](https://github.com/YoussefHegazy74/flame-in-freefall)

A data platform for NASA microgravity combustion research, built for the NASA Space Apps Challenge 2026. It includes a verified ETL pipeline, a read-only FastAPI and DuckDB API, and a Next.js interface for exploring spacecraft fire-safety data.

### [Basira](https://github.com/YoussefHegazy74/basira-ai)

An Arabic NLP and RAG platform for verifying Islamic content against Quran, Hadith, and Tafsir sources. Answers are grounded in retrieved passages with source citations.

### [Customer Insights & Prediction System](https://github.com/YoussefHegazy74/customer-insights-prediction-system)

An end-to-end data engineering and machine learning project: SQL Server database and warehouse, Airflow ETL, an XGBoost churn model, a Streamlit app, and a Power BI dashboard.

### [AI-Powered Library Management System](https://github.com/YoussefHegazy74/AI-powered-library-management-system)

A Laravel 11 library management application with catalog, borrowing, and admin workflows, plus local LLM assistance through Ollama.

### [AI Educational Video Generator](https://github.com/YoussefHegazy74/Ai-Video-Generator)

An early-stage multi-agent pipeline for turning book pages into whiteboard-style educational videos. The script and whiteboard-direction agents are implemented; the remaining pipeline is in progress.

### [Pollution Predictor](https://github.com/YoussefHegazy74/pollution-predictor)

Air pollution forecasting with Random Forest regression and classification models, exposed through a Flask API with Google Earth Engine data integration.
